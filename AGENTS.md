# Project layout

- Keep `AGENTS.md`, `spec.md`, `prompts.md`, and `index.html` at the project root. GitHub Pages serves the root `index.html`.
- Put planning notes and sketches in `00_planning/`.
- Put data files in `01_data/`.
- Put hand calculations and test cases in `02_validation/`.
- Put screenshots and exported results in `03_output/`.

Save every new file in the folder that matches its purpose. Keep the web app in the single root-level `index.html`; do not add other application files.
